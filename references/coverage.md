# What is included and what still needs help

This package uses fresh, general guidance. It does not include raw source packs, named operator recipes, private client facts, transcript libraries, fixed campaign recipes, or internal scripts.

| Area | Included method | Where | Limit |
|---|---|---|---|
| Idea to build | Eight steps with outputs and done checks | SKILL.md | Cannot fill unknown business facts |
| Better questions | Field states, small rounds, follow-ups, blockers | interview.md | Questions must fit the actual task |
| Scope and limits | Skill check, plain admission of gaps, pushback | limits.md | No skill can replace missing evidence or human approval |
| Customer evidence | Goals, doubts, attempts, buyer context, source care | research.md | A sample is not proof of the whole market |
| Offer and journey | Real terms, delivery, first value, later choices | offer-brief.md | New strategy, price, or forecasts need a specialist |
| Data grounding | Source list, live comparison, input map, conflicts | evidence.md | Does not teach causal analysis or data engineering |
| Clear copy | Reader questions, argument, proof, states, fallbacks | copy.md | Cannot approve unsupported claims |
| Plain voice | Fifth-grade words, voice sample, fact-preserving edits | writing.md | No claim to beat AI detectors |
| Page CRO | Page type, promise, proof, friction, downstream result | surfaces/pages.md | A pattern does not prove lift |
| Signup and quiz CRO | Needed fields, branches, auth, access, first value | surfaces/signup.md | Security and sensitive data rules need the right owner |
| Form CRO | Field purpose, errors, save/resume, useful submits | surfaces/forms.md | More submits do not prove more useful leads |
| Popup CRO | Trigger, repeat, suppression, priority, access | surfaces/popups.md | Timing is a project choice |
| Paywall CRO | Plan terms, billing states, payment and access checks | surfaces/paywalls.md | Billing and price decisions need the right skills |
| Onboarding CRO | First value, needed steps, return and stalled states | surfaces/onboarding.md | A pattern is not proof of cause |
| After purchase | Delivery, booking, prep, recovery, later use | post-purchase.md | No private cadence or sales script included |
| Screen craft | Questions to blocks, hierarchy, input truth, render checks | screens.md | New design work may need a dedicated design skill |
| Build handoff | Real components, live diff, contracts, states, proof | build.md | New tools or code areas may need another skill |
| Plays to test | Patterns from public operator talks for offers, low ticket, calls, sales videos, ads to page, positioning, stores, apps, keeping buyers, health | plays.md, plays/ | Test ideas only; numbers are stated, not checked |
| Measurement | Number definitions, known limits, test needs | measurement.md | No universal test size, time, or causal answer |
| Delivery | Source spec, builder view, six-part prompt, cold read | *-template.md | Only checked work can be called ready |

The core skill helps organize and check work. It routes deeper work to an available skill or the right person. It does not pretend to contain every skill named here.
