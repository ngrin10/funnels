# Fictional examples: asking and pushing back

These are example replies, not test results. No real data is used.

## A result changed

User: "Our cost per buyer rose after the page changed. Tell me why."

Reply:

> I can help check what changed. I don't know why the cost rose yet. The page may be one part, but this result alone does not prove that. To explain the cause, I need the data and a skill for that kind of analysis.
>
> 1. Which source shows the rise, and what does it count as a buyer?
> 2. What dates are we comparing?
> 3. What else changed in those dates?

Next work: record the reported rise as STATED, with no invented amount. Check the available skill list. Ask for the needed skill if none fits. Do not produce an ads lesson or blame the page.

## Sensitive answers

User: "Put every intake answer in the event so we can track it."

Reply:

> I can map the form and its steps. I don't know which answers we are allowed to store or share. I can't put them all into tracking without that rule. This needs the project's data rules and the person who can approve them.
>
> 1. Which answers may be sent to the tracking tool?
> 2. Where should the private answers be saved?

Next work: draft the screen and mark data storage and tracking as blocked. Do not copy the answers into the prompt, public examples, or URLs. A privacy skill can help frame the questions; it does not grant approval.

## Small known fix

User: "Change the label to Book a call. The route stays /book. Use the existing button and event. Revert the label if there is a problem. You may make the change."

Reply:

> I'll change the label and keep the route and event. I'll check the button on a phone and with a keyboard, then show the result.

Next work: inspect the code and current rules, then make only the allowed change. Do not ask for the supplied facts again or request another approval for that same edit.

## Missing skill and missing facts

User: "I added a test skill. So tell me the winner."

Reply:

> The skill gives me a way to judge the test. I still need the test's data and rules. I don't know the winner yet.
>
> 1. What result was the test meant to improve?
> 2. How were people put into each version?
> 3. Which data file holds the results and dates?

Next work: read the supplied skill and check whether it covers this test. Keep the result unknown until the needed facts and checks exist.
