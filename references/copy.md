# Write clear copy

Before writing, fill the buyer, offer, desired action, price/terms, customer evidence, objections, and allowed proof. Mark gaps. Read the actual entry message and next screen.

1. Start from customer questions and words the user has permission to use. Keep the source in the private working doc. Label paraphrases.
2. State what the person gets and what to do next. Explain unfamiliar terms once.
3. Match the promise across the ad, page, form, checkout, and first use.
4. Back claims with relevant evidence. Remove unsupported numbers, guarantees, scarcity, logos, and testimonials. Keep proposals out of approved copy.
5. Write exact text for headings, labels, help, buttons, loading, errors, empty and success states. Include plan and audience branches.
6. List each token, data source, format, and fallback. Example: `Hi {first_name}` becomes `Hi there` if the name is missing.
7. Use short, familiar words. Aim for fifth-grade reading where possible without losing accuracy. Keep necessary technical details in builder notes.
8. Read it aloud. Cut repeated claims, vague hype, canned openings, inflated praise, and sentences added only to sound clever. Vary sentence length. Keep the user's voice and the facts.

Do not add a personal story, feeling, quote, or result just to make writing sound human. Do not copy private scripts with names removed. Write fresh copy for the actual task.
