# Forms

Use for leads, demos, contact, applications, surveys, and other data collection. Use the signup guide for account creation. For a form inside a popup, use both guides.

## Give each field a job

| Field | Why needed now | Who uses it | Required or optional | Allowed values | Error and help text | Safe home |
|---|---|---|---|---|---|---|

Ask whether a field can be removed, read from an allowed source, or asked later. Do not make that choice blindly. A longer form may be needed to route the right request; measure useful results as well as completions.

## Make the task clear

Say what the person gets after submit, who responds, and when, using checked facts. Avoid false privacy promises, speed claims, and security badges. A placeholder is an example, not the field's only label.

Start with a clear single-column flow unless the real content calls for another layout. Group related fields. Use choices when the options are known and free text when they are not. Provide an escape when none of the choices fit.

For a long form, define steps, progress, back, edit, save, resume, and expiry. If one answer changes another field, say when old answers are kept or cleared.

## Handle errors well

Use useful validation without showing errors before the person can finish typing. Put the error by the field and explain the fix. On submit, focus the first error and keep entered values. Cover slow requests, lost connection, duplicate submissions, and successful submission with a failed confirmation screen.

A loading state should prevent an extra charge or duplicate record without trapping the person forever. Let the server confirm success. Decide how retries find the first result.

## Check the outcome

Define form views, starts, errors, attempts, successful submits, and the useful downstream result. Do not send typed answers or personal details in error events by default. Record only the allowed fields.

Test phone keyboards, autofill, keyboard-only use, long answers, required fields, optional fields, server errors, and resume. Deliver exact labels, help, buttons, errors, confirmation text, and proof.
